# 私有偏好空模板

这三节放进本批 `投递证据/<批次>/批次/Query.md`（完整格式见 [daily-batch](daily-batch.md#querymd)），按用户原话填写；空值不是已确认。此模板没有默认城市、方向或就业路径。

```markdown
## 硬范围
地区:
届别:
用工:
职责:
城市: （不限写“不限”）
依据:

## 偏好轴
用工路径: （用户原话）
城市: （用户原话；关系写成 A > B / A ≥ B / A = B / A ? B）
方向: （用户原话）
实习政策: 不收实习 | 单独批次 | 转正实习排最后
冲突策略: 用户决定
依据:

## 默认岗位次序
（本批用户原话）
依据:
```

另记录生效时间、替代版本、用户指定复查范围和首轮停点。关系对象、逐岗包、公司覆盖字段见 [偏好与证据契约](preference-contract.md)。`cities: []` 只表示不限城市，轴原话仍可记录排序；未确认字段保持待核。不得把实际个人取值写回公共模板。

默认岗位次序与公司确认规则、internship_policy 可选值均见[契约](preference-contract.md)；空白不代表已确认。
