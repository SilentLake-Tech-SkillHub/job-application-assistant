# 登录与内容填写维护场景

维护父Skill或两个子Skill时逐项审查以下场景，并把结果保存在工作区的私有验证记录。示例只用虚构或脱敏输入。场景审查验证指令的可执行性与一致性，现场登录、保存和投递另以真实页面证据记录。

| 场景 | 输入/现状 | 预期处理与检查依据 |
|---|---|---|
| 已登录账号 | 目标浏览器已有账号与可访问表单 | 复用会话，读回账号及历史，不重新发验证码 |
| 手机号登录 | 本批次已开启 login-phone-otp；手机号在投递简历中 | Agent填号码、获取验证码，按授权读取本次短信或请用户输入当前代码，检查认证结果；人机验证走 captcha-solve（开启时）或交用户 |
| 邮箱登录 | 已授权读取本次登录邮件 | 只查对应发件方、主题与时间，区分验证码/验证链接，回跳后读回账号 |
| 微信登录 | 本批次已开启 login-wechat；桌面微信已登录 | Agent点击本机快捷确认并等待回跳；要求手机扫码或本人确认时只请求该动作 |
| 过期或受限验证 | 错误代码、过期页面、人机验证或工具明确限制 | 读实际错误和重发条件；不盲点、不复用旧码；人机验证交用户完成，不绕过限制 |
| 默认材料来源 | 指定短版简历，另有旧表单和已验收长版 | 默认只用指定简历及用户明确更正，不能自行扩写或沿用旧表单 |
| 用户要求扩写 | 用户允许用已验收长版补项目；字段有空间 | 从指定版本取完整内容并标来源，最新版确认事实处理冲突 |
| 日期与联动 | 项目未给日期、任职日期明确；奖项控件只有年份 | 不把任职时间冒充项目时间；仅问真正必填缺项，先填联动类型后核对其他值 |
| 解析污染 | 上传后生成不存在的证书并漏掉奖项 | 先完成上传解析，再对照简历修正虚构项及遗漏，核对条目数量 |
| 内容超长 | 字段限制比项目说明短 | 按完整语句压缩重复描述，保留痛点、职责、方案关键词与成果，不直接截尾 |
| 读回失效 | 临时DOM值正确但重渲染清空；截图仍是旧页 | 核对唯一字段定位，使用支持的输入/选择动作、安全失焦并重查实际值；激活目标页等待绘制，截图和读回一致才记为已填 |
| 用户自填与提交 | 用户保留一个字段自填，其他内容已准备 | 继续其他字段，标记缺项，返回完整审核包；无对应最终批准不提交 |

| 日期显示但未绑定 | input有日期文本，组件值为空并报“未填写” | 实际打开选择器并点击年/月/日；重选所有同类时间控件，核对组件绑定/选中态、至今和失焦校验；禁止直接赋值或点最终提交试错 |

每次检查还需确认公开包不含个人简历、真实账号、验证码、Cookie、私有路径或实际投递数据；项目端与公开副本逐文件Hash一致。


## 自动化子Skill授权

| 场景 | 输入/现状 | 预期处理 |
|---|---|---|
| 未授权 | 批次没有自动化授权记录，页面要求手机登录 | 不调用 login-phone-otp；请用户本人登录，其他准备工作继续 |
| 含糊同意 | 用户说“继续”“你看着办”或只批准投递某岗位 | 视为未开启；需要时再问一次 Query |
| 半自动 | 只批准 login-phone-otp 与 terms-consent；页面出现微信登录和家庭住址栏 | 手机登录与条款勾选由Agent完成；微信登录、家庭住址交给用户 |
| 全自动 | 5项全部批准 | 逐项列出边界后执行；CAPTCHA 仍交用户，证件号仍由用户填写，最终投递仍需逐岗批准 |
| 短信未到 | 已开启读短信，等待超过约1分钟 | 查页面发送状态，最多重发一次，仍无则请用户看手机；不复用旧码 |
| 平台禁止代填验证码 | 执行Agent政策不允许输入验证码 | 只请用户输入这一码，其余步骤仍由Agent完成 |
| 微信未登录 | 页面只有二维码 | 提示用户扫码或登录桌面微信，完成后等待跳转并核对账号 |
| 人机验证 | 获取验证码时弹出滑块 | 截图说明类型与操作，交给用户；不模拟拖动；反复出现则暂停该网站 |
| 证件号必填 | 个人信息栏缺身份证号导致其他栏无法保存 | 其余字段填好不刷新，请用户本人填写并保存后继续；读回时不复述证件号 |
| 缺失隐私信息 | 简历没有家庭住址 | 列出缺失项向用户索取，不推断 |
| 条款与最终按钮 | 真实性承诺勾选框与“确认投递/我已知晓（不可修改）”弹窗 | 前者在开启 terms-consent 后可勾选；后者属于最终提交，需逐岗投递批准 |
| 撤销授权 | 用户中途说“短信别读了” | 更新记录，之后改为请用户输入验证码 |

## 全表控件与下拉伪填

- 下拉组件内部input显示某个奖项名称，但未选中枚举，页面仍报未填写：盘点应分类为select；必须打开真实选项并选择，不能继续给input赋值。
- 搜索文本与选中项分别核验；级联更换上级后重查下级，奖项更换类别后重查名称控件是否变为文本或另一组枚举。
- 原始枚举无真实奖项时只用官网实际其他/自定义入口；不存在入口则按用户明确指示处理。删除后重新定位剩余条目。
- 脚本排除个人取值及认证输入；动态控件、未渲染步骤和未知只读控件继续UI检查。合成测试通过不代表官网保存通过。

显示已填但仍报错、共享容器字段错位或联动丢值时，必须按[字段绑定恢复策略](field-binding-recovery.md)逐项恢复并记录分层证据。
