# 当前能力与验收边界

本包只消费用户正向评审确认后的投递批次（岗位交接/投递批次.json），不负责公司搜集、选岗或 Excel 转换与同步。

- 登录和岗位入口：已实现公司配置、原岗位恢复、账号匹配和人工验证码交接。各公司仍须实际适配与验证。
- 填写：已实现公司表单资产、条件探测、原子事实映射、冻结计划、填写及独立读回。公司资产未通过真实门禁时不执行。
- 收尾：固定事件及真实证据校验后，把每个岗位的最新结果覆盖写入 岗位交接/投递回传.json；不改主表，不读写 Excel。
- 尚未完成：通用文本简历导入、完整申请页条款引擎和最终提交执行。OCR 不在范围内。
- Hook：本包包含宿主路由和回执检查，真实阶段由 MCP 判断。脚本测试不证明宿主已自动触发。
- 浏览器：Chrome broker 和内置浏览器桥接必须分别实际可用，不能因配置存在就报告运行成功。
- 验收：代码测试、网页填写、草稿保存、用户核对、最终提交与官方回执分别核实。不得复用旧执行记录作为本次完成证明。

通用控件类型、动作与读回已收拢至共享控件合集，入口与扩展约定见 [通用控件合集](control-collection.md)。运行时通过 runtime_info.controlCapabilities 返回实际已加载的能力定义。

REA 被动结构证据、实际控件采集、映射候选、统一模板生成及连续推进见 [通用表单流程](generic-form-pipeline.md)。同一接口服务不同公司；不宣称所有未知框架都已具备驱动。缺少真实选项、日期交互、上传回显或宿主 REA 能力时返回具体建库缺口，禁止以 userOnly 或占位选项放行。
