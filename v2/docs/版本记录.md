# 当前修复记录

## 2026-11-10 · 2.0.0-alpha.40

用户授权推进定向岗位、按当前状态派发、确认回刷和对话交接。关联 Issue #65，回滚基线 `15b9354`。

- 定向登录调用可传预期岗位编码。组件在开页前核对该编码与任务编号是否对应。
- 组批使用公司宽表的当前岗位状态。读取原队列时重新识别已投、关闭和待处理回传，仅派发可执行任务。旧队列和任务记录保留原编号、顺序、页面及核验证据。
- 投递端在查看当前队列、派发和执行时读回最新交接。搜索端的确认回刷把当前岗位状态更新到交接宽表。
- 离线与真实部署验收在工作区任务单登记。现有表单模板、交接内容指纹、提交授权和官网回执契约沿用。
