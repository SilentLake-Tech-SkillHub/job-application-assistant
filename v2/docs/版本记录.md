# 当前修复记录

## 2026-11-06 · 2.0.0-alpha.17

按用户要求在整个投递产品移除独立公司模板封存文件的生成和读取。公司填写模板自身保存实际填写失败字段，现有页面采集、选项和真实核验结果各自保留一个来源。建库检查继续在正式模板保存前执行；已建好模板的复用不依赖独立封存文件。

修复采集证据复用取错展开记录的问题，以及未覆盖问题被发往定位修复的问题。公司模板更新时先补默认页面路径，再继承已有栏目及重复字段；重复记录的选项使用既有选项定义。浏览器桥补齐读取添加记录控件的 repeatDiscovery 接口。模板更新登记使用当前已完成的公司草稿契约保留未展开记录的既有映射，修复草稿完成后仍被旧正式契约阻断的问题。完整页面核验后，对仍存在的同一条记录中确实已缺席且不在新模板的旧字段清除旧映射，保留个人事实及尚未展开的其他记录。独立封存文件用一次性迁移清除，原模板和真实核验结果逐项读回。所有已绑定公司需做前后就绪对照，真实网页验收另记在工作区任务单。

回滚代码基线为 `75d2c1e`。按用户最新要求，发现差异后直接做一轮控件补全与对应公司填写模板更新，并报告更新项。
