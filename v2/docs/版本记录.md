用户要求任意对话均可调用投递 MCP，新分支有独立对话，同一 Agent 或 Agent 组沿用执行身份，并明确要求登记与修复。关联 Issue #64，回滚基线 `863e8c7`。

- 首次阶段调用按需加载本轮指令，退役按对话维护的运行身份台账。版本判断使用 CLI 和 MCP 共同的请求校验，调试接口继续提供真实版本读回。
- Agent 编码、组标识与核心连接使用稳定部署身份。内置浏览器桥使用实际浏览器和 Agent 执行主体，保留岗位标签、文档代际和目标页检查。
- 提示、接续和审计按对话及回合关联。对话登记及期限用于提示。冻结交接、公司资产、既有队列和回执数据沿用原契约；旧内置浏览器桥换指纹后按原岗位页面核对流程接续。
- 验证覆盖首调用、新对话、分支、无对话字段、不同 Agent、组内成员、版本失配和原任务接续。真实宿主结果在项目任务单登记。
