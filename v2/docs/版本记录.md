# 当前修复记录

## 2026-11-17 · 2.0.0-alpha.66

按用户已确认的新决定修复，范围以部署工作区需求文档6.6和任务C48为准。回滚基线d7f6cae；通用Issue #71、PR #72。

- 岗位名/岗位编号缺失或不一致只保留观察，不阻断建库、交互测试、恢复、填写和独立字段核验。位置、登录、控件内容和提交授权规则保留。
- 入口标题第一次读取失败继续其它公司并复查，第二次沿既有登记进入截图兜底；截图确认已是申请表可直接接续，不重复点击入口，实际登录页仍识别。
- 登录等待按公司返回原任务复查信息，轮到时自查，不要求用户回复；批次报告包含可执行清单，Stop Hook按权威整批清单核对未完成事项。
- 填写现状先核实后修复：普通匹配字段原本已跳过；新增现有搜索选择实体独立读回，不要求本岗位旧点击回执。匹配的前置布局字段和已齐的重复条目只读，不重复操作；真正新增条目仍检查单写者。
- 组件外浏览器设置支持分身与主用Chrome，空值询问。主用Chrome按部署登记的Agent插件执行，保留原浏览器、借用页和资料目录，不使用主用Chrome远程调试端口、不复制profile或Cookie。
- 主控与业务核心使用相同的工作区解析；安装端仅配置交接目录时也读取外部浏览器选择，防止main选择被跳过并误连分身。新增真实子进程回归，旧代码先复现失败。
- 主用Chrome通过现有扩展HTTP接口提供同一页面适配器，复用控件库、真实DOM读回、截图遮罩和采集流程；REA通过当前标签的实际CDP命令转发获取原始数据，原始输出不修改，异步事件流限制记录于结构元数据。
- Hook回执按真实调用方会话检查，缺失每次提示但不拦截；以索引引用避免反复扫描大记录。MCP可选conversationId逐调用传入实际宿主对话ID，元数据在业务参数解析前移除、不跨调用沿用，不改变执行身份与业务授权。错误和管理返回同样提示。H2-B未实施。

影响：正式公司模板、冻结计划和业务状态不迁移；新观察结果不更改旧已完成模板的可用性。更换浏览器或真实文档改变时重新绑定/读回，保留原页面。字段独立核验和具体提交授权继续执行，本轮验收不提交任何岗位。

验证：新增已填内容复用、重复条目只读、无标题顺延、入口复查/兜底、计数稳定/重采、浏览器选择/登记、扩展命令/标签绑定/截图遮罩、Hook回执及整批收工回归。最终离线与真实结果见工作区唯一任务单；真实网站/多宿主验收不以离线通过代替。
