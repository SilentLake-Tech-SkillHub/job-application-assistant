# 项目部分的范围更新

用户仅更新项目部分时，当前选择唯一保存在私有主档 `applicationSelections.projects`；`entities.projects` 和原始事实仍保留本人历史经历，不把未选用于本次申请的项目说成不存在。`profile_select_projects` 只接收已知项目编码及用户真实原话，不改教育、工作、城市、日期、联系方式、照片或原始材料。项目文本通过既有原文事实入口更新；确属项目内容的派生字段同步使用同一正式来源，不机械替换所有旧简历来源。

所有当前及后续准备共用该选择。选择回传列出每份有项目映射的本地表单；旧模板仍引用已排除项目时，冻结与执行前拒绝。已有模板没有删除、提交回执没有改写，标记只用于未来复用。历史已投网站不重新登录、不回改；不在现有打开任务中的网站只报告项目部分需现场读回或重建，不能以本地资料更新冒充官网更新。

`role_remove_project_record` 先把已确认排除项目与原队列、岗位、账号、当前名称及全部项目顺序绑定为预览，再用该预览摘要执行。Phoenix 驱动只在同一项目记录、没有其它记录或其它栏目控件的容器内解析唯一删除动作。先落一次尝试并清除旧核验/计划，再点一次；超时或结果不明不重复点。双次读回要求剩余记录名称及顺序精确等于原列表减去目标，所有非项目字段值摘要不变。失败时旧报告不能继续当完成证据；恢复只通过实际读回，不靠删除止损或 Agent 自述。

删除后仅重新采集、映射和封存受影响项目结构，保留非项目控件与事实；不能按旧的 occurrence 把后续项目误配给被删除项目。实际条件探测和现有旧映射退休检查仍生效，不伪造缺失回执。完成后整表独立读回、截图遮盖检查，再回到提交前审阅。

影响评估：当前网页移除一条重复记录会改变后续同标签题目的 occurrence、当前模板和冻结计划，不允许继续使用旧报告。迁移是保留页面、重新采集该岗位、按真实剩余项目名称重新映射、正常封存和核验；其他公司的历史运行/已提交记录保留。只更改项目文字且控件结构未变时不重建、不重新上传。数据表中没有简历项目字段的账本无需更改，不因项目更新同步改投递状态。
